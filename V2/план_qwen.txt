#### 1.3 Signal filters (D5, D6, D14, D17)

**Файл:** новый `services/signal_filters.py` (тонкий слой — здесь уместен)

```python
MIN_QUOTE_RESERVE_USD = Decimal("1000")
MAX_NET_PROFIT_PCT = Decimal("50")
MAX_WITHDRAW_FEE_RATIO = Decimal("0.1")
MAX_MIN_CONFIRM = 2000

def pre_quote_filter(pool) -> tuple[bool, str]:
    if not pool.get("pool_version"):
        return False, "unknown_pool_version"
    if pool.get("reserves") is None:
        return False, "reserves_unavailable"
    return True, "ok"

def post_signal_filter(signal, direction: str) -> tuple[bool, str]:
    if Decimal(str(signal.get("net_profit_pct", 0))) > MAX_NET_PROFIT_PCT:
        return False, "unrealistic_profit"
    # Direction-aware MEXC gates:
    # A (DEX→MEXC): нужен token_deposit
    # B (MEXC→DEX): нужен token_withdraw
    if direction == "A" and not signal.get("token_deposit", True):
        return False, "mexc_deposit_closed"
    if direction == "B" and not signal.get("token_withdraw", True):
        return False, "mexc_withdraw_closed"
    ...
```

**D6 clarification (Gate 1):**  
- ASS direction B + withdraw OK → **не** авто-reject.  
- Reject только direction A при `deposit=False`.

**D17:** при JOIN NULL → `token_deposit_enable=False` / `withdraw=False` (fail-closed), не True.

Wire в `_write_signal` / signal_writer.

**Критерий:** 0 сигналов с `net>50%`; 0 с empty `pool_version`; ASS-A режется, ASS-B может жить.

- [ ] Watcher expiry динамический
- [ ] `gas_estimate_fallback` < 5/час
